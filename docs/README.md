# Documentation

This repository includes infrastructure automation for a Kubernetes cluster on AWS plus Prometheus/Grafana monitoring.

See the following documentation pages for detailed guidance:

- `architecture.md` — cluster architecture, AWS topology, and monitoring components.
- `monitoring-dashboard.md` — Grafana dashboard guidance, alert examples, and Prometheus rule details.
- `cleanup.md` — teardown instructions for Terraform and the monitoring stack.

Screenshots and diagram assets are available in `docs/screenshots/`.
